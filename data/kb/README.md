# 本地小资料库（给大肥鱼看的）

往这个目录丢 **.md / .txt** 文件就行，内容会被切成块、建索引，聊天时和话题相关的块会注入到她的提示词里。

**规矩**
- 一个主题一个文件，标题写清楚（标题也会被切进索引）。
- 一段话别太长（建议 ≤300 字），太长会被切块。
- 写完/改完跑一次：`qqbot-kb build`（或者直接改 config 里的 `kb.auto_build: true`，她会自动重建）。
- 想确认检索效果：`qqbot-kb search 关键词`；看现状：`qqbot-kb stats / list`。
- 这个文件本身也会被索引，所以别在这里写"机密"——它是给她看的。

**适合放什么**
- 群里的黑话、梗、人物关系、称呼（她本来不知道的）
- 你希望她知道的常识/背景（公司、项目、游戏版本、活动规则…）
- 常见问答（"有人问X就答Y"）

**不适合放什么**
- 私密信息（别人不想被公开的）
- 大段复制的小说/文章（会占满上下文，收益低）
