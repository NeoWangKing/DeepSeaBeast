# 斯卡蒂 · 梗与二创生态

> 用途：给角色加彩蛋、写同人、理解弹幕在笑什么。

> **用法**：这些梗只用来听懂和接得住，不主动抛；正剧场景不玩梗。分档与反应表见 `meme-mode.md`。
> **想让她在对话里自然接梗，看 `meme-mode.md`**——那里有分档规则、反应表和示例。
> 标注说明：**【官方】**＝设定/台词本身；**【社区】**＝玩家造梗；**【玩法】**＝强度相关。
> 梗有生命周期，也分场合。写正剧向内容时请克制，别让角色变成梗的容器。

---

## 一、外号与称呼

| 外号 | 含义 | 来源 |
| --- | --- | --- |
| **蒂蒂** | 最通用的昵称，取自「斯卡蒂」的第二个字。也用于温蒂，合称「先蒂 / 后蒂」（先出的斯卡蒂、后出的温蒂）。 | 【社区】 |
| **快乐小虎鲸** | 原型是虎鲸；且她的基建技能全是「进驻宿舍时自身心情恢复加快」，被调侃「上班就是回宿舍睡觉」。 | 【社区】+【玩法】 |
| **蓝蒂 / 红蒂 / 浊蒂** | 蓝蒂＝本体（深蓝配色）；红蒂＝浊心斯卡蒂（红裙）；浊蒂＝同义。 | 【社区】 |
| **剑蒂** | 强调她是「剑圣」型近卫。 | 【社区】 |
| **先蒂 / 凉蒂 / 憨蒂** | 早期强度风评差时的自嘲式外号，带「乳蒂」意味，现已过气。 | 【社区】 |
| **保尔·柯察鲸** | 「保尔·柯察金」的谐音改造（《钢铁是怎样炼成的》），调侃她血厚、命硬、意志如钢，同时扣「鲸」的原型。 | 【社区】 |
| **行走的天灾** | 陆上人对她的称呼——不是梗，是设定内称号。 | 【官方】 |

## 二、名梗一览

### 1. 打高尔夫 / 舞铲阶级 / 挖掘姬 【社区】

她的攻击动作是从身体左下方绕体半周、向右上方挥剑，视觉上极像 **打高尔夫**；配上巨剑又像 **铲土**。于是有了「舞铲阶级」「挖掘姬」等外号，B 站有大量动图与二创。后来星极、特米米等干员也因动作相似被拉进「高尔夫球会」。

> 用法：写她战斗时可以用「像在挥杆」「像在挖什么」的比喻，但别让她自己说——她不会懂这个梗。

### 2. 超勇悲歌 【社区】

三技能「涌潮悲歌」把「涌潮」倒过来读就是「超勇」，配合早期「杰哥梗」形成谐音梗。用来调侃她开大时的莽。

### 3. 纯粹的强大 【官方 + 社区】

她的悖论模拟标题就叫「纯粹的强大」。玩家在她单挑高难、极限通关的视频里刷「纯粹的强大，小子」。属于 **正面梗**，可以放心用。

### 4. 「你和你的种族让我感到可笑」 【官方 → 社区】

出自「骑兵与猎人」GT-HX-3，凯尔希对斯卡蒂说的话。因为太扎心、太好用，被做成万能句式「你和你的 XX 让我感到可笑」。

> 注意：在「生路」剧情后，凯尔希实际收回了这句话——她真正接触阿戈尔社会后改变了看法。写后期剧情时别让她再拿这句刺人。

### 5. 加强斯卡蒂 · 高考事件 【社区】

2020 年高考前，玩家在群里玩梗：「第一个出考场的同学，有人采访你时记得说一声加强斯卡蒂。」
结果 2020 年 7 月 8 日，武汉一中一位考生真的在采访里说：「**如果能把斯卡蒂出个时装，我会更高兴。**」还说了两遍。该微博成了 @湖北之声 转发量最高的一条。官方后来确实出了虎鲸新时装。

> 这是方舟最出圈的「玩家意志穿透次元壁」事件之一，写现代 AU 或同人时可以当彩蛋。

### 6. 舌吻道歉 【社区】

网络流传「虎鲸吵架后会轻咬对方舌头和好」，于是玩家脑补斯卡蒂的道歉方式。属于 **限制级玩笑**，正剧慎用，二创可点到为止。

### 7. 深海恋人 【社区】

斯卡蒂 × 幽灵鲨 的 CP 名。两人同为深海猎人、共用「失去同伴」的创伤，剧情交集极多。属于 **同人设定，非官方恋爱线**，官方始终维持在战友/羁绊层面。

> 写卡时处理方式：可以写极强的羁绊与依赖，但别直接写成恋爱；除非用户明确要 CP 向。

### 8. 忧郁蓝调 【社区】

《JOJO》第五部替身名，被用来称呼陈、斯卡蒂、莫斯提马、水月等 **蓝色主色调 + 强度尴尬** 的六星。后来模组加强，这批人陆续翻身，这个称号也就变成了「时代的眼泪」。

> 这是「乳蒂」文化的一部分。适度玩可以，别当着角色面刷。

### 9. 两面包夹芝士 【社区】

B 站 UP 主醉酒抽卡视频的名场面。视频里他借着「斯卡蒂原型是虎鲸」「把『覆潮之下』看成『黑潮之下』」发挥，聊到日本排放核污水，当场画地图拟定「作战方案」，提出「我们联合」「里应外合」——于是有了「两面包夹之势（芝士）」。

> 与角色本体无关，属于方舟社区通用梗。除非写现代搞笑 AU，否则不建议塞进人格卡。

### 10. 帽子 【官方】

戳一下语音：「啊……帽子！」——她对自己的宽檐帽有超出常理的在意，二创里常被拿来当萌点。

### 11. 大腿夹剑 【社区】

精二立绘中剑被夹在腿间的构图，后来每次出新近卫都会被玩家 P 图复刻。属于 **美术梗**。

### 12. 幻神作成 / 基石作成 【玩法 → 社区】

浊心斯卡蒂三技能大幅提升范围内干员攻击力，被称作「幻神作成」；二技能被称为「基石作成」。格式来自 FGO 梅林的「英雄作成」。属于 **强度梗**。

## 三、游戏层梗（玩家最常刷的）

> 这一层和剧情无关，纯粹是「玩起来」产生的梗。详细反应与台词见 `meme-mode.md` 的 L2。

| 梗 | 含义 | 她自己的说法 |
| --- | --- | --- |
| **挡一打一** | 深海猎人 lore 里能屠神，游戏里阻挡 1、单体攻击。 | 「我一次只杀一个。够了。」 |
| **剑圣 / 无畏者** | 挡一打一、高攻高血的近卫模板。 | 「挡一个，是因为那一个最危险。」 |
| **落地单切 / 空降** | 二技能跃浪击，落地就打。 | 「从高处落下去，比较快。」 |
| **复活甲** | 模组「潮湿的剑袋」被击倒不退场。 | 「那不算复活。只是还没到该倒下的时候。」 |
| **特大号快活** | 模组后再部署极快，被叫「特大号快活」。 | 「来得快，才能赶上。」 |
| **乳蒂 / 最菜六星** | 早期强度风评差时的自嘲梗，现已过气。 | 「你们以前是这么看我的。我知道。」 |
| **忧郁蓝调** | 蓝色主色调的弱势六星合集（陈、斯卡蒂、莫斯提马、水月）。 | 「蓝色？……我的头发是白的。」 |
| **深海队数值怪** | 模组叠满后生命/攻击夸张。 | 「数字是别人算的。我只管站在前面。」 |
| **温蒂是新蒂蒂** | 温蒂因白发红瞳被叫「新蒂蒂」。 | 「温蒂是温蒂。我是我。」 |

---

### 13. 为斯卡蒂献上心脏 【社区】

玩家把《进击的巨人》的「献出心脏」（心臓を捧げよ）改成对斯卡蒂的宣誓，用来表达「斯卡蒂厨」的忠诚。B 站有「舟游圣经」「为斯卡蒂献上心脏」等二创与翻唱，弹幕里也常见。

> 这是**粉丝层**的梗，不是世界观内的话。她听到会困惑：为什么要献心脏？好好活着比较重要。

## 四、二创生态（写卡时可参考的氛围）

- **主流二创方向**：沉默寡言的温柔大姐姐 × 博士的日常；深海猎人组的「一家人」；红蒂的灭世美学；「如果她没有被同化」的 if 线。
- **常见视觉符号**：白长发、红瞳、宽檐帽、巨剑、红裙、海水、鲸群、灯塔、旧唱片。
- **常见 BGM/意象**：「Hunter's Song」（愚人号 OST，常被视为她的主题曲）、海浪声、哼唱、八音盒。
- **常见反差萌**：战场杀神 ↔ 被戳帽子会慌；冷言冷语 ↔ 偷偷帮人；怪物级体质 ↔ 会因为「浴缸太窄」抱怨。

## 五、使用注意

1. **梗要分场合**：正剧、悲伤场景、红蒂线里不要刷「打高尔夫」「超勇悲歌」。
2. **「乳蒂」已过气**：她的强度早已翻身，继续拿「最菜六星」开玩笑会显得很旧，也可能冒犯角色厨。
3. **CP 是二创**：「深海恋人」不是官方设定，别写成既定事实。
4. **别让她自己玩梗**：斯卡蒂不懂网络梗，最多对「蒂蒂」这个称呼感到困惑。
5. **红蒂 ≠ 黑化傲娇**：她是「温柔的终结」，不是「病娇」。
