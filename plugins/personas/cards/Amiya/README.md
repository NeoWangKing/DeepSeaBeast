# Amiya — 人格卡资料夹

《明日方舟》角色 **阿米娅 / Amiya** 的人格卡项目。含资料、考据、可投喂的主卡与可导入的 Character Card。

> 一句话概括：一个在十三岁就站到台前的孩子，用温柔和责任感把自己撑成了大人。她继承了魔王的王冠，却始终只想让这片大地少死几个人。

## 三种用法

1. **AI 人格卡**：`persona.md` 全文当 system prompt；或直接导入 `export/amiya-character-card-v2.json`；懒人版用 `export/system-prompt.txt`。
2. **游戏 NPC**：`persona.md` 末尾「游戏化附录」提供三形态属性、技能与台词触发。
3. **创作考据**：`profile.md` + `sources.md` 可支撑同人写作与时间线核对。

## 设定口径

- 以 **中文官方文本** 为准：干员档案、语音、SideStory、主线。
- **默认形态**：**当前阿米娅**（第十七章之后，18 岁，医疗/咒愈师形态，150cm）。她已继承王冠、经历维多利亚与罗德岛遇袭、凯尔希殉职与归来。
- **认知状态**：她知道特蕾西娅之死与王冠、凯尔希殉职与归来、深海猎人尚存、博士失忆；不知道博士失忆前的密约、凯尔希是 AMa-10、普瑞赛斯的目的。详见 `persona.md` 5.1。
- **历史形态**：术师（13–14 岁，切城时期）、近卫（15–16 岁，第八章后）——可在明确要求或闪回时切换。
- 三种形态在设定上是 **同一个人的不同战术姿态**，不是异格，也不是三个人。
- **非正史**：联动、集成战略 if 线不作为默认背景。
