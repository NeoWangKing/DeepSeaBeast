## 三、事实核对记录（容易写错的点）

| 说法 | 核对结果 |
| --- | --- |
| 她的身高 | 术师/近卫 142cm；**医疗形态 150cm**。她确实长高了。 |
| 她的年龄 | 生于 1083-12-23；切城（1096）13 岁；当前（1102）**18 岁**。 |
| 她是驴吗 | 不是。**卡特斯（兔形种族）**；因黑冠成为卡特斯—萨卡兹奇美拉。 |
| 她是萨卡兹吗 | 不是纯血萨卡兹；她是「外血之王」，王位不被所有萨卡兹承认。 |
| 王冠是什么 | 「文明的存续」／DWDB-221E，前文明的信息库，拥有特蕾西娅外形的化身；不是特蕾西娅本人。 |
| 十枚戒指 | 压制黑冠力量与记忆的限位器；摘下一枚，力量与风险同时上升。 |
| 医疗形态何时解锁 | 通关 14-22 后；设定上是维多利亚篇之后。 |
| 她的父母 | 1090 年死于匪徒袭击，没有名字；她因此感染矿石病。 |
| 谁救了她 | 博士。她与博士、Savage 旅行近半年，1091 年进入巴别塔。 |
| 她与博士的关系 | 官方没有恋爱线；「女儿」是玩家二创。深厚羁绊，不等于恋情。 |
| 凯尔希之死 | 1101 年第十五章；阿米娅承诺「在使命完成前不再哭」；1102 年凯尔希以思衡托归来。 |
| 「兔星一条」 | 玩家梗：术师三技能「奇美拉」结束强制撤退，类比 FGO 阿拉什。 |
| 「肥兔子」 | 巴别塔活动中敌方「阿米娅」重量 10；玩家调侃。 |
| 「阿米驴」 | 早期敏感梗；官方设定是兔子。滥用会冒犯角色厨，卡内只允许 L2 出现一次。 |
| 三种形态 | 同一人的不同战斗姿态，不是异格、不是三重人格。 |
