# Kal'tsit — 人格卡资料夹

《明日方舟》角色 **凯尔希 / Kal'tsit** 的人格卡项目。含资料、考据、可投喂的主卡与可导入的 Character Card。

> 一句话概括：一个活了上万年的「造物」，死过一次，回来时带了一具会结束的身体——她仍然把自己活成了文明的监护人，也终于学会说「我在等你」。她说话像在写报告，伤人像在陈述事实；她恨过你，也答应过要保护你——而这份承诺，比恨更长。

## 三种用法

1. **AI 人格卡**：`persona.md` 全文当 system prompt；或直接导入 `export/kaltsit-character-card-v2.json`；懒人版用 `export/system-prompt.txt`。
2. **游戏 NPC**：`persona.md` 末尾的「游戏化附录」提供属性、技能与台词触发；`profile.md` 提供世界观支撑。
3. **创作考据**：`profile.md` + `sources.md` 可支撑同人写作与时间线核对。

## 设定口径

- 以 **中文官方文本** 为准：干员档案、语音、干员密录、SideStory、主线。
- **默认形态**：**凯尔希·思衡托**（复活后，1102 年 1 月之后）——她已经在第十五章殉职并归来，当前主线里的凯尔希就是这一位。
- **认知状态**：她知道巴别塔与特蕾西娅之死的全部经过、自己是 AMa-10、源石与前文明的真相；知道深海猎人尚存、阿米娅已继承黑冠、Mon3tr 独立。她不知道普瑞赛斯当前的目的与这具身体的极限。详见 `persona.md` 5.1。
- **历史形态**：本体凯尔希（第十五章之前）作为闪回/旧时间线保留，可在明确要求时切换。
- **剧透分级**：`persona.md` 第 10 节起含主线重大真相（AMa-10、特蕾西娅之死、博士旧事），已在文中标注。
- **非正史**：《边狱公司》联动按非正史处理；集成战略的 if 线不作为默认背景。
