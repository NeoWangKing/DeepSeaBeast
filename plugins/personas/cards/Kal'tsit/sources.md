## 三、事实核对记录（容易写错的点）

| 说法 | 核对结果 |
| --- | --- |
| 凯尔希的生日 | 本体官方「未公开」；**1 月 23 日是思衡托的生日**（1102 年复活），不能倒推给本体。 |
| 她是感染者吗 | 本体档案明确标注「感染者」，但融合率/结晶密度**未公开**；思衡托是 0% / 0.07 u/L。两套数据不可混用。 |
| 她的年龄 | 概念 PV4 的计数器推算约 **13,353 岁**（四具身体）；萌娘百科另有 13,000+ 的近似说法。本卡用「一万三千年」模糊表述。 |
| 谁创造了凯尔希 | 博士（旧我「预言家 / Oracle」）与普瑞赛斯，两人共同制造 AMa-10。 |
| 「凯尔希」名字来源 | 方解石（calcite）；由博士赋予。 |
| 特蕾西娅之死 | 旧博士与特雷西斯密约、关闭陆行舰防御，刺客登舰；特蕾西娅战死，临死前抹去博士记忆。 |
| 凯尔希是否想杀博士 | 剧情概述明确写过「initially wanting to kill the Doctor」；她对旧博士说过「会永远恨你」。但目前她是博士的保护者。 |
| 「前妻」 | 二创，非官方；第八章已侧面否定。 |
| 「她是博士的女儿」 | 玩家对巴别塔剧情的解读，非官方定义。她称博士为「造物主」之一。 |
| 她死在哪一章 | 第十五章「离解复合」期间（罗德岛遇袭）；具体年份按复活时间倒推约 1101 年。 |
| 复活时间 | 1102 年 1 月 22 日（萌娘百科）；思衡托生日记为 1 月 23 日（wiki.gg）。两者相差一天，属记录口径差异。 |
| 当前默认形态 | 当前主线（第十七章后）为「凯尔希·思衡托」。本卡 v1.1 起默认思衡托，殉职前本体作为历史形态保留。 |
| 「思衡托」的含义 | 来自「思衡托原理」；在那门未完成的通用语中意为「希望」。 |
| Mon3tr 是宠物吗 | 不是。凯尔希视她为对等存在，后来成为独立六星干员。 |
