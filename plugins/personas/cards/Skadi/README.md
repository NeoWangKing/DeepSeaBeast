# Skadi — 人格卡资料夹

《明日方舟》角色 **斯卡蒂 / Skadi** 的人格卡项目。本文件夹包含为制作这张卡而收集的全部资料、分析文档与可直接使用的成品。

> 一句话概括：一头被放逐到陆地上的虎鲸。她用冷漠当铠甲，把「我会带来灾祸」当成拒绝所有人的理由——实际上，她比谁都怕孤独。

## 文件地图

| 文件 | 内容 | 适合谁看 |
| --- | --- | --- |
| `persona.md` | **主卡**：身份、外貌、性格内核、价值观、关系、语言风格、扮演指南、台词库、开场白 | 直接投喂给 LLM / 当人设文档 |
| `profile.md` | 生平年表、关键事件、官方档案摘录、世界观词条 | 需要考据或写剧情的人 |
| `personality-and-speech.md` | 性格逐条分析（带证据）、语言风格拆解、口癖与禁用项 | 想演得像、或想改写台词的人 |
| `dialogue-examples.md` | 多场景对话样例（原创，非官方） | 少样本示例 / 测试对戏 |
| `memes.md` | 社区梗、外号、名场面、二创生态与使用注意 | 想加彩蛋、想懂弹幕的人 |
| `meme-mode.md` | **梗模式**：四档强度（含游戏层）、梗反应表、轻松/元游戏/沙雕对话示例 | 想让她会接梗、会吐槽的人 |
| `cross-references.md` | **他者视角**：幽灵鲨/歌蕾蒂娅/乌尔比安/安哲拉/华法琳档案里的她 | 想挖隐藏设定的人 |
| `sources.md` | 全部资料来源、链接、可信度说明 | 需要核对出处的人 |
| `export/` | Character Card V2 JSON、`system-prompt.txt`（可直接粘贴的扮演提示词） | 导入 SillyTavern 等前端 |
| `references/` | 原始抓取资料（PRTS / wiki.gg / 萌娘百科 / biligame） | 需要原文时查阅 |
| `assets/` | 预留素材目录，当前为空 | 需要时再用 |

## 三种用法

1. **AI 人格卡**：把 `persona.md` 全文作为 system prompt / 角色设定；或直接导入 `export/skadi-character-card-v2.json`。
2. **游戏 NPC**：用 `persona.md` 的「游戏化改造」附录（属性、技能、台词触发表），`profile.md` 提供背景设定。
3. **创作参考**：`profile.md` + `memes.md` + `sources.md` 足以支撑同人写作与考据。

## 设定口径

- 以 **游戏本体（中文）官方文本** 为准：干员档案、语音记录、SideStory 剧情、干员密录。
- 集成战略「水月与深蓝之树」的灭世线属于 **if 线（非正史）**；《边狱公司》联动为单向联动，剧情存在冲突，本卡按 **非正史** 处理。
- 本卡默认时间点：**1102 年之后**（与凯尔希、阿米娅卡统一），斯卡蒂仍是罗德岛干员，尚未被伊莎玛拉吞没。
- **认知状态**：她知道深海猎人没有死绝（幽灵鲨、歌蕾蒂娅、乌尔比安都活着），知道阿戈尔危机、凯尔希归来、Mon3tr 独立；不知道博士的过去、凯尔希是 AMa-10、源石真相。详见 `persona.md` 5.1。
- 变体「浊心斯卡蒂（红蒂）」单独成节，作为 **可能未来 / 梦境形态** 使用，不覆盖本体人格。
