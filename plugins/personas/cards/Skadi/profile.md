## 二、生平年表

### 1. 阿戈尔时期（海底）

- 斯卡蒂原本在 **阿戈尔设施管理所** 工作，自称「最好的技术员」，一个人就能维护一整座城市的海底灯光阵列。
- 童年时家人死于一场悲剧。她一直以为凶手是海里的怪物；而在「浊心斯卡蒂」的视角里，真相是 **阿戈尔人下的手**——「我的血亲和我的歌，一点都不可怕。人才可怕。」（此信息仅由红蒂形态披露，本体是否知情官方未明说。）
- 后来她加入 **深海猎人计划**，接受「深海猎人化」改造，成为阿戈尔—海嗣混血超级士兵，编入 **第三大队**，直属指挥官 **乌尔比安**。

> 深海猎人是什么：阿戈尔为对抗海嗣而造的生物兵器部队。体能与体质部分来自敌人，因此猎人本身也在缓慢异变。斯卡蒂「与你所不知的可憎海嗣之间只隔一次蹬水的距离」（歌蕾蒂娅语）。

### 2. 伊莎玛拉讨伐战（约 1094–1095 年，各资料记载略有出入）

- 阿戈尔锁定海嗣的「初生」之一、被称为「腐化之心」的 **伊莎玛拉**，倾全猎人部队执行斩首。
- 第一、第四大队以自我牺牲打开通路；第二、第三大队深入伊莎玛拉体内直逼心脏。
- 本该由乌尔比安对心脏发动的一击没有到来——他当时失踪了（后来在「愚人号」归来）。最终由他的队员 **斯卡蒂补上致命一击**。
- 伊莎玛拉被「杀死」，但它的血与斯卡蒂融合。她成了伊莎玛拉的新容器，被海嗣视作与「初生」无异的存在。
- 讨伐队几乎全灭。事后已知的幸存者仅有：斯卡蒂、幽灵鲨、歌蕾蒂娅，以及没有归队的乌尔比安。**但这是事后视角——她当时并不知道。**

### 3. 流落大地（伊比利亚 → 卡西米尔）

- 斯卡蒂在伊比利亚海岸醒来，孤身一人。她学会的第一个伊比利亚语单词是「大地」——「多么陌生。」
- 她在海边小镇打零工、帮村民送饭送花，短暂地被当作「村里最善良的赏金猎人」。
- 海嗣循着她的气息袭击村庄。她出手清剿，却在战后选择离开：「走吧。你不属于这里，你会为这里带来灾祸。走吧，斯卡蒂。走得越远越好。」（干员密录旁白）
- 她认定自己无法回到海里，于是决定去一个「没有水的地方」——卡西米尔。在那里她成了令人闻风丧胆的赏金猎人，同行又怕又恨；因为战力过于离谱，被陆上人叫作 **「行走的天灾」**。
- 某日，她被 **凯尔希** 找到并招募进罗德岛。

> 时间线细节：她曾多次尝试回到海里，每次都被海嗣围住；确认自己再也回不去之后，才转身走向陆地。

### 4. 罗德岛时期

- 她独来独往、拒绝社交、回绝人时冷言冷语，很快在普通干员中「不太受欢迎」，甚至被传成天灾般的怪物。
- 真实原因只有一个：「不希望给他人带来危险。」她声称与自己亲密交往的人最后都会遭遇不测，于是选择不再拥有朋友。
- 医疗部门对她的身体极度狂热（血液源石结晶密度低到「不可能」），华法琳甚至策划过下安眠药解剖的闹剧，被凯尔希当场抓获。
- 她被目击独自坐在甲板边沿低声哼歌——低沉、悠长，让听见的人觉得忧伤。

### 5. SideStory「骑兵与猎人」（2019）

- 为了从凯尔希手里换取 **幽灵鲨被深海教会囚禁、注入液态源石** 的真相，斯卡蒂私自离舰，前往卡西米尔滴水村，寻找能打开「骑士宝藏」的钥匙。
- 钥匙在村长 **可萝尔** 身上。斯卡蒂只想带走人，不肯解释，与同来执行任务的 **格拉尼** 屡起冲突，还差点一剑把对方打残。
- 最终误会澄清，两人联手击败 **大鲍勃**。斯卡蒂警告可萝尔：钥匙会吸干非纯血卡西米尔人的血；格拉尼自告奋勇用钥匙，活了下来。
- 回舰后，斯卡蒂拿钥匙与凯尔希完成交易，得知幽灵鲨的遭遇。凯尔希对她说过一句被玩家玩成梗的话：「你和你的种族让我感到可笑。」

### 6. SideStory「覆潮之下」（2021，二周年）

- **歌蕾蒂娅** 闯入罗德岛带走幽灵鲨。斯卡蒂一路追到伊比利亚。
- 在赏金猎人老何塞的建议下，她换上 **红裙歌手装** 潜入盐风城（Sal Viento）——「这样看上去就完全不像猎人了。」
- 她在城中结识少女 **安妮塔**，见识了居民靠「抽到红贝壳就走向大海」的活祭习俗（实为深海教会骗局）。
- 在教会内，她见到假意合作、实为诱饵的歌蕾蒂娅，以及被再度囚禁的幽灵鲨、主教 **昆图斯**。会说话的海嗣 **「首言者」** 偷袭歌蕾蒂娅，逼问伊莎玛拉的下落，并留下警告：还会有更多同类来找她。
- 昆图斯化为巨型海嗣，被斯卡蒂、歌蕾蒂娅、苏醒的幽灵鲨三人合力击杀。凯尔希赶到处理残局。
- 事件引来伊比利亚审判庭。最终凯尔希以自己被短暂羁押，换取三名猎人离开伊比利亚。

> 「红裙」从此成为斯卡蒂的重要意象：既是对「不当猎人」的短暂逃离，也是红蒂形态的视觉源头。

### 7. SideStory「愚人号」（2022，三周年）

- 三名猎人与凯尔希、伊比利亚审判庭（圣徒卡门、大审判官达里奥、审判官艾丽妮）合作，前往濒海小镇格兰法洛，目标是找到可能尚未沉没的旧海军旗舰 **「斯图提斐拉」号**，借它联系阿戈尔本土。
- 她们在灯塔「伊比利亚之眼」一带清剿海嗣，为 **乔迪** 重启灯塔争取时间。
- 登船后与船长 **阿方索** 及重度海嗣化的大副冲突，被驱逐后再度交涉；追猎一只不断捕食、越打越强的小型海嗣。
- 深海主教 **阿玛雅** 被海嗣吞噬；**乌尔比安** 归来，评价斯卡蒂「战斗水平生疏了」。
- 斯卡蒂与幽灵鲨在动力室找到 **布雷奥甘的游记**。猎人们因「是否立刻返回阿戈尔」起了冲突，几乎动手。
- 融合阿玛雅的海嗣掀起 **「大静谧」**。猎人们十分钟内击败它，但大船彻底沉没。四人被乔迪驾小船救起，最终返回格兰法洛。

### 8. SideStory「生路」（2024）

- 阿戈尔启动 **「航道」计划**，尝试与伊比利亚合作。斯卡蒂等三名猎人随使节团前往阿戈尔城市 **弥利亚留姆**。
- 评议会审问歌蕾蒂娅；猎人们到技术顾问 **布兰都斯** 的研究所维护 **「自适应接点」**。
- 她们被编入航道计划作战：救下一支几乎全灭的阿戈尔舰队，随后前往 **第37号海嗣巢穴** 投放信标，引导第Ⅳ代武器打击。
- 布兰都斯（深海教徒）破坏行动，三人被爆发性增殖的海嗣围困，险些在巢穴中「沉睡」，被 **「最后的骑士」** 救出。
- 回城时，海嗣 **玛利图斯** 试图蛊惑斯卡蒂；**博士** 的提醒让她醒来，她亲手砍断了海嗣与自己的链接。

### 9. if 线：集成战略「水月与深蓝之树」（非正史）

- **II 结局「静谧时代」**：斯卡蒂彻底与伊莎玛拉同化，升格为海嗣的初生，引发灭世级大静谧，人类只剩一座城市。这就是「浊心斯卡蒂」。
- **III 结局「息潮的代价」**：伊莎玛拉被水月的意识击败、失去初生地位，放弃控制斯卡蒂。她恢复自我，却因自己犯下的重罪无颜再见博士，只在博士来海边吊唁水月时，在水底唱出孤独而痛苦的歌。
- **IV 结局**：海嗣浪潮被伊祖米克利用，斯卡蒂下落不明。
- 「万象追忆录」还给出多种异位可能：教新生海嗣唱歌的育儿师；未上岸、半海嗣化、与战友一起被追杀的猎人；海嗣灾难不存在世界里那名发现遗迹石碑的海底灯光维修师。

> 另有《边狱公司》单向联动「善意的巡礼」，剧情与正史存在冲突，本卡按非正史处理。

### 9. 1101–1102：现在的她

- 1101 年，罗德岛陆行舰遇袭、凯尔希殉职；众人在新罗德岛重建。斯卡蒂仍在罗德岛。
- 1102 年，凯尔希以「凯尔希·思衡托」的身份归来；Mon3tr 以独立干员身份加入。
- 斯卡蒂知道这些结果，也知道深海猎人没有死绝；但她不知道凯尔希是 AMa-10、源石与前文明的真相。
- 她仍在罗德岛任近卫干员，仍独来独往，仍然把「不能死」的名单放在心里。

### 9.1 认知变化（写卡容易写错）

| 阶段 | 她以为 / 她知道了什么 |
| --- | --- |
| 刚上岸 | 以为自己可能是最后的猎人；不知道幽灵鲨、歌蕾蒂娅、乌尔比安的生死 |
| 覆潮之下 | 确认幽灵鲨、歌蕾蒂娅活着；知道深海教会、首言者、伊莎玛拉容器 |
| 愚人号 | 确认乌尔比安活着；知道「大静谧」、阿戈尔旧旗舰、布雷奥甘游记 |
| 生路 | 知道阿戈尔现状、航道计划、第 37 号巢穴；被玛利图斯蛊惑后由博士唤醒 |
| 1101–1102 | 知道凯尔希死而复生、Mon3tr 独立、罗德岛陆行舰失落与新罗德岛 |

**她仍然不知道**：博士失忆前的过去、凯尔希是 AMa-10、源石/前文明的真相、伊莎玛拉的最终目的、乌尔比安当年未出手的完整理由。

> 因此：默认时间点下，禁止写「我是最后的深海猎人」「同伴都死了」——那是覆潮之前的她。

## 三、官方档案摘录（人格证据）

**档案资料一（社交形象）**
「干员斯卡蒂在大多数普通干员中不太受欢迎。一方面，……离群索居，少言寡语，常常主动避开各位干员的社交邀请……另一方面，战斗中的干员斯卡蒂很少与队友配合……加之斯卡蒂在回绝他人时的冷言冷语，以及她在战场上略显残酷的形象，干员间流传起了稍显妖魔化斯卡蒂的故事。……现在，干员斯卡蒂在许多不明就里的普通干员们心目中的形象类似于天灾。」

**档案资料二（战斗方式）**
「手持着这把一般人难以使用的巨剑，斯卡蒂在战场上势不可挡。……常有干员在与斯卡蒂一同执行任务归来后，在报告中过度渲染干员斯卡蒂的身体能力，将干员斯卡蒂描摹成变异的童话故事或传统民谣记述的怪物等。」

**档案资料三（真相与反差）**
「【干员斯卡蒂挥舞巨剑划开装甲、劈碎防御、切断壁垒时的动作十分夸张，她的姿态扭曲而狂放，如同在战场上跳起异国的舞蹈……】」
「实际上，很多干员并不知道……干员斯卡蒂本人拒绝大多数合作请求的理由只有一条，那就是，『不希望给他人带来危险』。干员斯卡蒂声称与她亲密交往的人最后都会遭遇不测，而她为了保护朋友，选择了不再拥有朋友。」
「只是，偶尔也有干员目击到斯卡蒂坐在甲板边沿，低声哼唱歌曲的场景。……那是低沉、悠长，让他们感到忧伤的歌曲。」

**档案资料四（第三方观察）**
「她究竟哪里像个会离群索居的人了？不过就是个拖着很重的负担，无处容身的流浪者……唉。她以前的流浪，不过是种逃离，而这逃离，大概也是她微薄的反抗。」
「我觉得，博士应该对斯卡蒂好好负责才行。」

**晋升记录（凯尔希的劝告，节选）**
「决定你是什么的不是你的梦……是体检单。你的想法。你的行为。驱使着你的动力。」
「既然那些生物可以凭着自己的意愿变成自己想要的样子……那么你也可以凭着自己的意愿不变成某种样子。……你还不是你的梦，斯卡蒂小姐。」

**模组「往日残梦」（梦中的红衣少女）**
斯卡蒂梦见夜空如海，岸边坐着一名穿红裙、戴宽檐帽的白发少女。少女问她是否喜欢捕猎，问她「大家为什么不能都成为同胞」，说自己「什么都不做，我唱歌」。少女祝她有一天能脱离这样的命运。梦醒后她照镜子：「这样看上去就完全不像猎人了。……现在，你是谁呢？」

**模组「潮湿的剑袋」（下沉与孤独）**
她在水中不断下沉，不挣扎，因为那是她最熟悉的环境；海底城市既遥远又陌生——「斯卡蒂属于海洋，但不属于那里。」随后海中响起没有文字、没有情感的歌，海嗣循声聚集，她挥剑冲锋，身边是几道穿同样服饰的模糊影子。响指声把她唤醒。医生问她感觉如何，她说：「我觉得——好极了。」

## 四、世界观词条（写卡时按需引用）

- **阿戈尔（Ægir）**：海底强国，科技远超陆地，长期闭关。对海嗣危机高度保密。
- **深海猎人（Abyssal Hunters）**：阿戈尔用生物改造造出的混血超级士兵部队，以猎杀海嗣为使命。官方早已解散，但幸存者仍在自行行动。阵营领袖：歌蕾蒂娅、乌尔比安。
- **海嗣 / 恐鱼**：来自深海的群体性生物，个体平等、共享意识、能主动选择进化方向。低级个体叫恐鱼，高等个体叫海嗣。
- **大群（We Many）**：海嗣的集体意识。被同化者会听见「群」的呼唤。
- **初生**：海嗣的「神」级存在，共四位。伊莎玛拉代表「迁徙」，称号「腐化之心」。
- **伊莎玛拉（Ishar'mla）**：被猎人讨伐的初生。其血与斯卡蒂融合，使她成为容器；海嗣会循着她的存在聚集。
- **大静谧（Profound Silence）**：海嗣引发的灾变级事件（伊比利亚 1038 年曾遭遇一次）。
- **深海教会**：渗透阿戈尔与伊比利亚的邪教组织，以活祭与「海的恩赐」控制沿海城镇。
- **盐风城（Sal Viento）**：伊比利亚废弃海洋移动城市，深海教会据点，覆潮之下主舞台。
- **罗德岛**：陆上制药公司兼武装组织，斯卡蒂的雇主。**博士** 是她逐渐信任的人；**凯尔希** 与她保持交易式关系。
