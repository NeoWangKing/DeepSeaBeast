## 三、事实核对记录（容易写错的点）

| 说法 | 核对结果 |
| --- | --- |
| 她是「最后的深海猎人」 | 是**覆潮之前**的主观认知（密录简介）；现在她知道幽灵鲨、歌蕾蒂娅、乌尔比安都活着。默认时间点禁止再写这句话。 |
| 伊莎玛拉讨伐战年份 | 萌娘百科写 1094 年，wiki.gg 写 1095 年 → 本卡模糊处理为「约 1094–1095 年」。 |
| 她杀死伊莎玛拉后成为容器 | 正确。乌尔比安未按约攻击心脏、当时失踪（后来在愚人号归来），由斯卡蒂补刀。 |
| 她的家人死于海怪 | 正史未明说；红蒂语音暗示是 **阿戈尔人** 所为。本卡标注为「红蒂视角披露」。 |
| 「蒂蒂」只指她 | 不是。温蒂也被叫「蒂蒂」，合称「先蒂/后蒂」。 |
| 「深海恋人」是官方 CP | 不是。官方为战友/羁绊，CP 属同人。 |
| 红蒂是「黑化」 | 不准确。她是被同化后的「温柔的终结」，不是病娇或傲娇。 |
| 覆潮之下她穿红裙 | 正确，为潜入盐风城伪装成歌手。红裙后来成为红蒂的视觉源头。 |
| 她的当前状态 | 1102 年之后仍在罗德岛；知道深海猎人尚存、凯尔希已归来、Mon3tr 独立；本卡默认时间点。 |
