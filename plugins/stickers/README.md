# stickers（表情包 / 贴图）

只管贴图这一件事：**库存、备注、分类、挑选、发送**。
**贴图不是图片**——核心那边是独立的 `sticker` 动词，插件只负责"挑哪张、这张叫什么"，
真正怎么送到对面由通道决定（QQ 现在是按图片消息发，以后可以升级成原生自定义表情）。

## 什么算「大肥鱼形象」

她是**以蓝色鲸鱼为原型的二次元形象**：蓝发（波浪长发）、大眼睛、**鲸鱼鳍状的耳朵**，
通常穿女仆装/围裙（围裙上有鲸鱼图案），有时带**鲸鱼尾巴**。

判定贴图时不看"画里是不是有条鱼"——要看**是不是她这个角色**。
同人不同画风（Q 版 / 插画）都算；颜色相近的猫、鲨鱼、蓝团子不算。

库存分区：

```
library/           在用的（目前 17 张，全部是她本尊）
library_rejected/  清出来的其它贴图（**没有删**，随时能挪回）
```

清理时确认过："简化蓝鲸团子"和"相似蓝发角色"都**不算**她，已一并移出。

## 数据（都在 `$DEEPSEA_PLUGIN_DATA`）

```
library/       图片本体（gif/png/jpg/webp）
index.json     {"items": [{id, file, desc, tags, group, used, last_used, size}]}
```

一条长这样（`desc` 是选片的关键）：

```json
{"id": "s1790876947821", "file": "s1790876947821.jpg",
 "desc": "拇指向上（简笔画笑脸）：表示肯定/「牛逼」，在夸对方刚说的梗，不是敷衍",
 "tags": ["点赞", "肯定", "牛逼", "夸", "接梗", "不是敷衍"],
 "group": "100000004", "used": 114, "last_used": 1792677629}
```

## 自动收集：群里别人发的贴图

她**从群里学新贴图**：有人发贴图 → 下回来存进库，标成「待打标」。

```
核心事件 message.received 带上 media: [{kind, name, url, file}]
   ↓
插件 collect_sticker(url)  →  md5 去重 → 存 library/ → 索引里标 status=pending
   ↓
待打标的**挑不中**（desc 空的匹配不到），打标之后才真正能用
```

| 限制 | 值 | 为什么 |
|---|---|---|
| 单张大小 | ≤ 2 MB | 大图没必要，且要 base64 发出去 |
| 每小时 | ≤ 20 张 | 防止有人刷图把库存塞爆 |
| 去重 | md5（库里已有的跳过） | 同一张图反复发只存一份 |
| 关掉 | `STICKER_COLLECT=0` | 环境变量 |

### 为什么要"猜"

SnowLuma **把 QQ 表情包降级成了普通 image 段**（实测原始数据只有 `file`/`url`，
没有 `summary` / `sub_type` / `emoji_id`），协议上分不出表情包和照片。所以判据是启发式：

| 判据 | 结论 |
|---|---|
| GIF（动图） | 算表情包 |
| 小方图（比例 0.72~1.4 且短边 ≤ 320 且 ≤512KB） | 算（可能是贴图） |
| 大图 / 横图 / 长图 | 不算，跳过 |

原则是**宁可漏收，不要错收**：收错了也只是躺在待打标里，不会发出去。

### 漏收怎么办：让她当场收

说「这张收下」「存成表情包」→ 她调 `collect_last_image(index=1)`，
把这个会话里**最近一张图**强制收进库（插件记着最近 8 张的地址）。

打标用 `note_sticker(id, desc, tags)`，打过标 `status` 自动转 `ok`，就能被 `send_sticker` 挑中了。
`list_stickers` 里待打标的会显示成「【待打标】文件名」。

## 三个工具（都要求通道有 `sticker` 能力）

| 工具 | 作用 |
|---|---|
| `send_sticker(query)` | 按情绪/意思挑一张发出去，例如 `"笑死"`、`"无语"`、`"点赞"` |
| `list_stickers(keyword)` | 看有哪些（按用量排序） |
| `note_sticker(id, desc, tags)` | 改备注 / 分类标签 |

## 怎么挑（不引入依赖）

```
得分 = 命中 tags × 3 + 命中 desc × 2 + log(1+used) × 0.5 - 太久没用的衰减
```

中文按字符二元组切词，英文按单词。**一个都没命中就不发**，直接说"没找到合适的贴图"。

## 找不到怎么办

返回 `{"ok": false, "error": "没找到合适的贴图…"}`，由模型用语言兜底（"这个我这儿没图"）。
